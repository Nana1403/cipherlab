How to solve Diffie Hellman Key Exchange

The Diffie–Hellman key exchange is used for two people to secretly create the same shared key over a public network.
Main Idea: Two people:
Alice
Bob
agree publicly on:
a prime number p
a base g
Then they create private secrets and exchange partial values.
In the end: both compute the SAME shared secret key.

Formalu's:
Alice’s Public Value - A=g^a mod p
Bob’s Public Value - B=g^b mod p
Shared Secret Key
Alice computes: K=B^a mod p
Bob computes: K=A^b mod p
